# W20: two conversions from the real panel, back to back, one per model, in a
# ui_test_* folder. Same TV/scripted method as browse.txt; real services
# (ui-test.sh never sets UI_FAKE).
#
# convert.txt (W19) was written before the UI redesign and no longer reaches
# the Convert dialog: its second Cross opens the first scene of "Unsorted"
# (the folder's focus starts on the first scene, not on "+ Add photos"), so
# Square/Cross land in the scene view and no job is enqueued. This script is
# the redesigned flow:
#   Albums (focus 0 = Unsorted) -> Right Right -> the ui_test_conv folder ->
#   "+ Add photos" -> Photos (Inbox tab, newest photo first) -> tick one photo
#   -> Square -> Convert dialog -> SHARP -> Start (job 1 enqueued) -> back to
#   the folder -> "+ Add photos" -> untick the first photo, tick the second ->
#   Square -> dialog -> DA2-Small -> Start (job 2 queued behind job 1) ->
#   Options -> Settings -> Conversions (Queue) -> the queue screen with both
#   rows -> back to the folder -> progress shots -> the two new scene tiles ->
#   view the first, R1 for the second -> quit.
#
# Preconditions on the console (W20 owns them, cleaned by exact name after):
#   * scenes/ui_test_conv/ exists and is empty (the album the scenes land in);
#   * inbox/ui_test_conv.jpg ($SPLAT_DATA_DIR/golden/immichvr/4.jpg) and
#     inbox/ui_test_conv2.jpg (.../5.jpg), the second uploaded last so it is
#     the newest Inbox tile (index 0) and the first is index 1;
#   * state/ui.json remembers "da2" before the run, so the first dialog lists
#     DA2-Small first and SHARP second (one Down picks SHARP); after that
#     Start the service remembers SHARP, so the second dialog lists SHARP
#     first and DA2-Small second (one Down picks DA2);
#   * a SHARP GGUF under models/ that the manager verifies in place (the
#     panel's Ready row) and state/models/da2.gguf, the DA2-Small GGUF.
#
# Expected klog (viewer.log of the run):
#   "viewer: jobs: queue .../state/jobs.json", "viewer: jobs: ui_test_conv2
#   queued/running ... ", a "done" row for each of ui_test_conv2 (SHARP) and
#   ui_test_conv (DA2), "viewer: scene ui_test_conv: ... splats", "viewer: tv
#   scene 1/2 ui_test_conv (album ui_test_conv)" then "2/2 ... ui_test_conv2",
#   "viewer: script done", "viewer: PASS, exit 0".
#
