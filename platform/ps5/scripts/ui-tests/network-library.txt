# A3.1/A3.2/A3.6: a network location, listed and opened, with no copy.
#
# The driver pushes state/locations.json before the run (console-run.sh), so
# nothing is typed on the on-panel keyboard here: the case is about the mount,
# the listing and the open.
#
# Home -> Options (Settings, depth 2) -> eight rows down to "Network locations"
# (Scale around, Move speed, Turn speed, Edge softness, Blending, Models,
# Conversions, **Network locations**) -> Cross opens the Locations screen.
#
# The first row is the configured location. Cross opens it as a library root
# (Scenes over the share); tile 0 is "+ Add photos" and tile 1 is the scene the
# SMB save uploaded (the NFS export is seeded with the same folder). One Right,
# then Cross, opens it in place. A remote scene is opened with OpenPath, so the
# line the app writes is the "opened from <id>" one:
#
#   viewer: location smb0 ready                     (the mount probe)
#   viewer: tv scene <name> (opened from smb0)      (opened from the share)
#
# (There is no "(album smb0:/...)" line: that form is only written for a local
# album. The old expectation asked for it and could never pass.)
#
# The location's Path is an empty sub-folder of the share (the driver makes it),
# so the library root holds no scenes of its own and the tile order is stable.
# No "copying" wait: the scene is read through the adapter, never written under
# the title's data folder.
