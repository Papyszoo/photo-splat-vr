# smoke4: folder and scene management through the TV panel, on the ui_test_*
# tree only. Same tour as W17's albums.txt / smoke3, with the two changes this
# console needs: VR9's QWERTY key coordinates and the extra folder tile
# ("test", not ours) that shifts the home grid.
#
# The keyboard is 10 columns (1-0, qwertyuiop, asdfghjkl + Shift, zxcvbnm,
# then . - _ Space Delete OK):
#   index 31 = 'x' (row 3, col 1), index 0 = '1' (row 0, col 0),
#   index 13 = 'r' (row 1, col 3), index 42 = OK (row 4, col 2),
#   index 40 = Space (row 4, col 0).
# In the old ABC grid 'x' was index 33 and 'r' index 17, so the Right counts
# are shorter here; a discrete press is far shorter than VR9's ~0.35 s repeat
# delay, so hold-repeat never adds a step.
#
# Flow: create folder x1 through the keyboard, rename it to x1r, move
# ui_test_a's scene into x1r, delete the empty ui_test_a, open x1r, rename the
# scene (append "r"), then delete it through the panel.
#
# Run: platform/ps5/scripts/ui-test.sh <this file>
#
# Preconditions (created outside the UI, by exact name):
#   scenes/ui_test_a holds a copy of 02_da2_photo1, scenes/ui_test_b a copy of
#   immichvr-2 (the folder the tour never touches), plus the existing empty
#   "test" folder. Home tiles when it starts (four columns per row):
#   0 Unsorted, 1 test, 2 ui_test_a, 3 ui_test_b, 4 New folder (second row),
#   so the script reaches New folder with one Down from Unsorted (Right does
#   not wrap to the next row).
#
