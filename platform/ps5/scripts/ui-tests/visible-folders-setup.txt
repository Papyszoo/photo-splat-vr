# This script is driven by visible-folders-check.sh, which puts two converted
# scenes on the console first (family-a/scene-a and family-b/scene-b) and reads
# the klog afterwards. Nothing here is chosen by hand.
#
# What it proves: a scene is open when the passcode is set (the allow-list starts
# empty), so the viewer closes it (viewer: hidden scene closed); ticking one album
# publishes that album only. The photo picker stays open, with every source
# (stage U1): the "photos-open" shot is the picker listing its sources, not an
# empty one.
#
# Settings: the focus starts on Scale; the System rows are Models, Conversions,
# Network locations, Visible folders, Quit, so Visible folders is nine Downs
# (stage T added the Thumbnail size row in Display).
# Home: the tiles are Unsorted first, then the folders by name (gallery.cpp's
# list_albums_all), and the check installs family-a and family-b, so family-a is
# tile 1 and one Right opens it. (The old one Down assumed four columns; with the
# stage T tile sizes the columns differ per step, and Right is the same move at
# every one.)
# The Visible folders screen's only action without a passcode is "Set a
# passcode": Cross, type 2468, OK, type 2468 again, OK.
# The unlocked list starts with "Scene folders" (a heading), then Unsorted,
# family-a, family-b, "Network", the scene locations, "Other" and "Other
# scenes". One Down from Unsorted is family-a; no photo row exists any more.
